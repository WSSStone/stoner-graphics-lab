# Feature 027 Metal Fixtures

This tree owns bounded conformance, shader, presentation, and failure fixtures.
Every checked-in binary or expected-value file has a repository-relative logical
identity, provenance, generation command where applicable, license status,
expected digest, and semantic purpose in its owning manifest or README.

Generated metallib files and compiler intermediates are not source fixtures;
they are rebuilt under ignored validation work roots from authoritative SPIR-V.
