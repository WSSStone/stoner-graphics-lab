# Feature 022 KTX2 Fixture Corpus

This directory freezes the portable-profile source and artifact evidence used by
`AssetKTX2Tests`. `Valid/*.source.bin` is the exact base-mip byte sequence
generated by the named test case. `Golden/*.ktx2` is produced only through
`FKTX2TextureCooker`; no native host encoder is an accepted producer.

Regenerate source and golden files from a strict Debug build:

```bash
Build/Mac/Debug/Tests/StonerTest \
  --suite asset \
  --emit-ktx2-dir Tests/Fixtures/KTX2/Golden \
  --emit-ktx2-source-dir Tests/Fixtures/KTX2/Valid \
  --ktx2-determinism-runs 1 \
  --report Validation/022/corpus.json
python3 Tests/Fixtures/KTX2/generate_invalid_fixtures.py
```

Use the platform-matching executable on Windows and Linux. The explicit
acceptance gate replaces `1` with `20` and must reproduce every digest below.
The ordinary Asset suite performs one complete golden comparison to keep local
iteration bounded.

## Quality And Size Gates

The 64x64 balanced profile cases are decoded through private libktx and checked
against the immutable Feature 021 source payload. The normalized JSON report
records the measured values, exact payload/reference byte counts, and the
following fixed acceptance thresholds:

| Evidence | Acceptance threshold |
|---|---:|
| ETC1S color PSNR | at least 35 dB |
| UASTC color PSNR | at least 40 dB |
| UASTC normal mean angular error | at most 3 degrees |
| UASTC normal p99 angular error | at most 10 degrees |
| ETC1S level payload / RGBA mip bytes | at most 35% |
| UASTC level payload / RGBA mip bytes | at most 40% |

The size denominator is the complete uncompressed RGBA mip chain rather than
the KTX2 file size, so container metadata cannot make a compression gate appear
better or worse. The current macOS reference run measured ETC1S at 45.449316 dB
and 194/21844 bytes, UASTC as exact for the color fixture and 5488/21844 bytes,
and the normal fixture at 0 mean and p99 angular error.

The independent validator still runs with `--warnings-as-errors`. Khronos
diagnostic 7010 is accepted only when the complete, duplicate-free set of nine
declared `stoner.*` metadata keys is present; any missing, additional, or
different warning/error fails the report. This narrow exception preserves
project identity metadata without weakening structural or DFD validation.

## Invalid Seeds

`Invalid/` contains bounded deterministic mutations generated from
`Golden/etc1s-color-balanced-full.ktx2` or
`Golden/uastc-color-balanced-full.ktx2`. The filename names the first intended
failure surface. Seeds cover identifier/header truncation, level-index
truncation and range/alignment faults, DFD/KVD/SGD range and overlap faults,
scope contradictions, and Basis payload corruption. Later mutation tests may
derive additional cases in memory, but every checked-in binary has a
reproducible mutation in `generate_invalid_fixtures.py`.

| Seed | Deterministic mutation | Intended first failure |
|---|---|---|
| `header-bad-identifier.ktx2` | XOR byte 0 of the KTX2 identifier | identifier |
| `header-truncated.ktx2` | retain only the first 79 bytes | fixed header |
| `level-index-truncated.ktx2` | retain only the 80-byte header | level index |
| `dfd-out-of-range.ktx2` | move DFD start to the final four bytes and set length 64 | DFD range |
| `kvd-overlaps-level-index.ktx2` | move KVD start to byte 80 | metadata overlap |
| `sgd-out-of-range.ktx2` | move SGD start to the final four bytes and set length 64 | SGD range |
| `level-overlaps-header.ktx2` | set level 0 byte offset to zero | level/header overlap |
| `level-out-of-range.ktx2` | set level 0 length to the complete file size | level range |
| `level-misaligned.ktx2` | add one to the UASTC level 0 offset | level alignment |
| `scope-two-faces.ktx2` | set face count to two | unsupported 2D scope |
| `scope-depth.ktx2` | set pixel depth to one | unsupported 3D scope |
| `basis-payload-corrupt.ktx2` | XOR the final ETC1S payload byte | Basis payload |

`AssetKTX2Tests` expands these seeds into a deterministic matrix of at least 40
cases. Every row carries the expected `EAssetResult`, diagnostic stage and
stable code; exact-limit and first-above-limit cases additionally identify the
bounded field. Corrupt ETC1S/UASTC and concurrent cook/open/load/transcode
tests prove that no partial artifact, payload, registry mutation, or stale
registration lease escapes.
