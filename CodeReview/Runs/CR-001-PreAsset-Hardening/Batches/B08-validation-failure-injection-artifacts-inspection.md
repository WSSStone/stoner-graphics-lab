## Confirmed Coverage

`Tests/DeferredNativeIntegrationTests.cpp` is the authoritative executable gate for the current implementation. It now requires required native mode when `STONER_REQUIRE_DEFERRED_NATIVE=1`, emits the readback report through `STONER_DEFERRED_READBACK_REPORT`, requires at least 18 probes for both `StandardZ` and `ReversedZ`, requires unique finite passing probes, requires the six local-light readback cases for each convention, and verifies final native live-object cleanup.

The CI wrapper for `native-lavapipe` sets:

- `STONER_REQUIRE_DEFERRED_NATIVE=1`
- `STONER_DEFERRED_READBACK_REPORT=<readback-output>`
- `STONER_DEFERRED_NATIVE_SHADER_DIR=<shader-directory>`
- `STONER_RENDERER_COMPARISON_REPORT=<comparison-output>`
- `STONER_RUN_DEFERRED_NATIVE_FAILURES=1`

This means the executable test remains the primary CI protection for current native readback and real failure-injection coverage.

## Drift Found

The retained Linux readback artifact is stale relative to the current B08-S11 implementation. It records:

- `draw_count=12`
- `light_count=3`
- `StandardZ` probe count: 12
- `ReversedZ` probe count: 12

It does not include the current local-light readback probe names: `point-visible`, `point-outside-view`, `point-camera-inside`, `spot-visible`, `spot-outside-cone`, or `spot-near-plane`.

`Validation/019/completion.md` points to the same older GitHub run and explicitly summarizes 12/12 probes per convention. That was valid for the original Feature 019 closeout, but it no longer proves the expanded native coverage introduced during CR001-B08-F005.

The CI wrapper also has a weaker post-run report validator than the executable test. `validate_readback_report()` still accepts any report with at least twelve probes per convention and does not check the required local-light probe names. Its unit test constructs and accepts a synthetic 12-probe report. Because the wrapper first runs `StonerTest`, this is not currently a bypass of the main native gate, but it weakens artifact-level proof and future maintainability.

## Finding

Accepted `CR001-B08-F006` as S2: Deferred validation artifacts and wrapper under-check local light readback coverage.

## Expected Fix Direction

B08-S14 should align the wrapper validator, wrapper unit tests, README/completion wording, and retained evidence policy with the current 18/18 local-light readback coverage. If fresh Linux CI artifacts are needed, they should be generated by a real native CI run and recorded with run/commit identity rather than substituted by macOS local evidence.
