# B00: Bootstrap

## Scope

Create the reusable review framework, independent environment, durable CR-001
state, Draft PR, fresh CodeGraph index, and pre-review build/test baseline.

## Results

- Dedicated branch and independent worktree created from the frozen baseline.
- `stoner-cr` reproduces Python 3.12 and SCons 4.10.1.
- Traceability seed contains all 463 FR/SC records.
- CodeGraph covers all 308 project C/C++ files under Source, Tests, and Demo.
- Debug and Release build successfully, but emit 33 warnings.
- The native deferred test failed once and passed twice on immediate repeats.
- Three-platform remote CI passed at the bootstrap HEAD.

## Decisions

- CR tools are agent-operated locally. Their CI runs only when reusable tool
  code changes; progress and finding documents do not trigger tool CI.
- Project CI remains required at fix-cluster/batch boundaries and closeout for
  cross-platform evidence.
- Build warnings and the intermittent native test are accepted findings for
  their owning batches; they are not silently normalized as baseline behavior.
