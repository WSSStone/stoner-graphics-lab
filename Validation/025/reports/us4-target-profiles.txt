Feature 025 US4 - Explicit Target Profiles
===========================================

Result: PASS
Host: macOS Apple Silicon
Configurations: Debug; Release strict (-Werror)

Profile and producer evidence
-----------------------------
- Canonical versioned Windows Vulkan, macOS Vulkan, and Linux Vulkan profiles
  explicitly declare backend-tagged SPIR-V, ordered texture capabilities,
  fallback policy, limits, and schema-versioned settings for every producer.
- Fixture SHA-256 values are recorded in fixture-manifest.json and verified.
- Generic cooked-family producers accept only codecPolicy=exact-v1 and reject
  missing, wrong-schema, unknown, or unsupported setting values.
- Renaming displayName preserves effective profile identity, derived keys,
  payload bytes, target decisions, and generation identity.

Target decision evidence
------------------------
- Image/texture decisions select the first payload-compatible declared target
  capability. Incompatible LDR capabilities use uncompressed fallback only
  when explicitly authorized and report bUsedFallback=true.
- The same incompatible request with fallback=fail is rejected before
  publication. Unknown texture capabilities also fail closed.
- Shader payload decisions require an exact backend/profile/format match.
  A valid Metal target profile without matching MSL payloads fails closed.
- Static mesh/model profile projection and decision remain target-independent.
- Every successful non-plan asset report records effective settings digest,
  relevant profile digest, normalized target selection, and fallback status.

Precise DDC invalidation evidence
--------------------------------
- Display-name-only mutation: every representative DDC entry reused.
- Platform/CPU-only mutation: every current payload-family DDC entry reused.
- Texture capability mutation: only image/texture entries recooked.
- Shader payload choice mutation: only material/shader entries recooked.
- Texture fallback and graphics backend affect only their declared families.
- An unsupported static-model producer setting is rejected only by the owning
  producer; unaffected family projections remain identical.
