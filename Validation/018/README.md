# Feature 018 Validation Evidence

This directory retains only contract-required cross-platform evidence. Build logs,
temporary reports, and local smoke output belong under `Build/`.

Required completion artifacts:

- `macOS/triangle.png` and `macOS/triangle.log`
- `Windows/triangle.png` and `Windows/triangle.log`
- `Linux/triangle-report.txt`
- `completion.md`

Do not add placeholder screenshots or fabricated logs. Each visible screenshot and
log pair must share one run ID and satisfy the validation contract in
`specs/018-triangle-demo-integration/contracts/triangle-demo-validation-contract.md`.
