Acceptance facts:
- One FStaticModelAsset is emitted per authored scene; exactly one records the
  source default scene where glTF supplies it.
- Parents precede children in deterministic depth-first order and roots retain
  authored scene order.
- TRS and matrix transforms are converted to the Unreal-style left-handed,
  Z-up basis; negative determinant evidence is retained.
- Shared meshes are emitted once and referenced from multiple models, while
  unreferenced meshes remain typed package outputs.
- extras.stonerAssetId produces key.* identities for meshes, scenes, and nodes;
  structural idx.* fallback identities are deterministic when keys are absent.
- Explicit mesh and scene identities survive source reorder and display-name
  changes under the same logical source path.
- cgltf mesh extras are recovered through its bounded copy API because the
  pinned parser stores mesh extras as source offsets for targetNames support.
- Cycles, multiple parents, duplicate/invalid keys, depth overflow, and empty
  scenes return no partial package outputs.
- Complete package metadata publishes in one FAssetRegistry revision; failed
  packages leave the existing registry revision unchanged.
- Twenty repeated multi-scene imports preserve package ordering and identity.

- glTF material/image/texture dependencies and Material v2 mapping (US3);
- comprehensive malformed/resolver/limit diagnostics (hardening and US5);
- Renderer/RHI realization and native transformed-mesh proof (US4).
