# Feature 024 Foundation RHI Gate

Date: 2026-07-31
Platform: macOS (Apple Silicon)
Environment: `conda run -n godot`

## Scope

- `FRHIBufferUploadDesc` checked range and non-retaining source contract.
- `FRHIIndexedDrawArguments` five-field contract.
- Host-visible direct writes and device-local Vulkan staging.
- Deterministic Vulkan record inspection and native visible-frame
  `vkCmdDrawIndexed` mapping.
- Deferred Renderer migration to explicit indexed arguments.

## Commands And Results

```text
conda run -n godot scons platform=Mac config=Debug strict=1 -j4
conda run -n godot Build/Mac/Debug/Tests/StonerTest \
  --suite coordinate-convention --suite rhi --suite vulkan \
  --suite deferred-renderer

conda run -n godot scons platform=Mac config=Release strict=1 -j4
conda run -n godot Build/Mac/Release/Tests/StonerTest \
  --suite coordinate-convention --suite rhi --suite vulkan \
  --suite deferred-renderer
```

Both configurations completed with exit code `0`. The focused RHI suite
reported `238` passing checks. The Vulkan suite covered full indexed argument
recording, device-local staging, host-visible writes, unsupported transfer
usage, and invalidated-buffer rejection. The deferred batching regression was
updated to assert the new `(firstIndex, vertexOffset, firstInstance)` layout.

## Note

The native visible-frame command binding now creates and owns a UInt16 index
buffer and calls `vkCmdDrawIndexed`; its platform-visible smoke evidence stays
with the existing Feature 018/019 native validation track. Full Feature 024
foundation closeout remains T037.
